## Run 7 held-mechanic resolutions

The normal MediaWiki API request for this pass returned HTTP 403. I did not try another endpoint or route; the wiki citations below use the already-read current revision 1134584 in this note. Donor citations name the pinned commit so the source variant stays explicit.

- **Malice safe tiles and Soul Cage:** Crystal selects connected groups of three from a shuffled eight-direction neighbor list in a 15×15 area around the room center, creating up to four groups (12 tiles maximum); Malice starts the cycle every 40s and reverts/damages after the default 3s, while Megalomania requests an 8s revert (`data-global/lib/quests/soul_war.lua:1006-1099,1191-1209`; `data-global/monster/quests/soul_war/goshnars_malice.lua:139-150`; `data-global/monster/quests/soul_war/goshnar's_megalomania_purple.lua:117-125`). The revert leaves ground id 409 safe and deals 8000 death damage to the top player on a non-409 ground; the guide independently advises standing on a white tile for the room hit (`data-global/lib/quests/soul_war.lua:1022-1059`; `ZJKtfyRCPjQ@06:05-06:40`). Recommendation: keep random group generation, ground restoration, and outside-safe-ground damage together in one native terrain rule; the fixed-tile draft is not equivalent.
- Crystal starts a Soul Cage 23s after the Malice lever; killing a cage schedules another after 23s. Each call to `SpawnSoulCage` with no named cage present schedules a 40s timeout; that callback looks up the current creature by the global name `Soul Cage`, and if it finds one, removes it, schedules another 23s spawn, adds +10 defense and +10% reflect for each listed damage type, and does not bind the timeout to the original actor (`data-global/scripts/quests/soul_war/soul_war_mechanics.lua:57-67`; `data-global/lib/quests/soul_war.lua:349-350,936-1004`). Thus an earlier timeout can consume and buff a successor created after a kill. Recommendation: use a name-wide callback queue and additive reflect state to retain this observed donor behavior; do not translate it to a per-cage deadline or the draft's 63s flag chain. The caption's reported kill window under 15s and boss absorption on failure are guide claims, not the source timer (`ZJKtfyRCPjQ@05:22-05:59`).
- **Greed sphere and cooldown:** Crystal starts the sphere phase after five Greedbeast deaths, makes Greed immune and immobile at the shield position, then releases on sphere death or after 34s; the sphere steps west once per 3000ms and fully heals Greed if its next tile contains the boss (`data-global/monster/quests/soul_war/goshnars_greed.lua:156-175`; `data-global/monster/quests/soul_war/soul_sphere.lua:90-124`; `data-global/scripts/quests/soul_war/soul_war_mechanics.lua:211-219`). Canary's pinned Greed boss uses a 45s fallback which restores mobility/position and removes the sphere (`data-otservbr-global/monster/quests/soul_war/goshnars_greed.lua:140-162`). Oteryn's existing Soul War reconstruction/parity lane is Crystal-based (`tools/content-schema/encounter-authoring/soul_war_crystal_reconstruction.py:5-10`; `crates/gameplay/dispatch/src/gameplay_transport/postgres_tests/soul_war_parity.rs:1-3`), so use Crystal's 34s plus death-release path for this reconstruction, while preserving Canary's 45s behavior as the explicit alternate donor; add deterministic west-step/collision and timeout state before claiming this mechanic playable.
- Crystal's Greed table contains an earlier `timeToFightAgain = 0` and a later `20 * 60 * 60`; in the Lua table the later value is effective. Its `onUseExtra` also keeps a world KV deadline, sets it to `now + 20h`, and clears the shared minion-spawn flag only after expiry; do not interpret the shadowed zero as no cooldown (`data-global/lib/quests/soul_war.lua:355-392`). The current wiki's 20h access-boss rule agrees on the interval (`Soul War Quest/Spoiler` revid 1134584).
- **Spite fire stomp:** the global event picks one of four fixed positions every 14s; an unstomped fire is removed after 5s and adds +10 defense if Spite still exists. Stomping removes the item only when that player's last stomp is at least 56s old (`data-global/scripts/quests/soul_war/soul_war_mechanics.lua:400-432,447-480`; `data-global/lib/quests/soul_war.lua:619-638`). The guide's estimate of roughly 40s for a personal reset is explicitly tentative and refers to its room-damage explanation, so use the pinned 56s stomp gate and keep it distinct from the global fire/removal cadence (`AR0TxuTv0rc@07:26-07:40`). Recommendation: model a world fire clock plus a per-character stomp timestamp; do not turn 56s into a shared encounter cooldown.
- **Cruelty / Greedy Maw:** the Maw action is per-player with a 30s cooldown; a successful use consumes the essence, reduces Cruelty defense by 2 when above base, lowers the shared defense-drain count, and writes the shared boss timestamp as `now+15s` (`data-global/lib/quests/soul_war.lua:32-35`; `data-global/scripts/quests/soul_war/soul_war_mechanics.lua:860-911`). Cruelty calls the growth helper after its first 15s; the helper waits until `last-use + 15s`, adds +2 defense, increments the shared drain count, and resets the timestamp to current time, so the first growth after a Maw use cannot occur before about 30s and later growths are 15s apart (`data-global/monster/quests/soul_war/goshnars_cruelty.lua:138-145`; `data-global/lib/quests/soul_war.lua:1477-1494`). Recommendation: carry separate player-use cooldown, boss growth timestamp, defense, and drain state; the unconditional repeating 15s draft timer is wrong. The guide likewise describes resistance accumulating over time (`t3GcDyTQsPk@06:16-06:27`).
- **Hatred:** the lever initializes one shared burn counter to 180; thresholds 180/135/90/45 select Ashes/Spark/Flame/Blaze by comparing the pre-decrement value, and using Sorrow consumes it and adds 10 to that same counter (`data-global/lib/quests/soul_war.lua:416-420,489-501`; `data-global/scripts/quests/soul_war/soul_war_mechanics.lua:577-639`). This is a shared scalar with threshold checks, not four independent forward-only timers; preserve a Sorrow-driven increase that can return through an earlier threshold. Two Condensed Remorse pickups are counted per player and reset that player's torment counter (`data-global/scripts/quests/soul_war/soul_war_mechanics.lua:672-695`); the guide calls for stepping on remains before the charge reaches 30 (`oOgX3QQtJxg@04:29-05:10`). The source adds the empowerment multiplier to boss defense on player hits but multiplies only primary outgoing damage, passing secondary damage through unchanged; boss disappearance removes the current Burning form (`data-global/scripts/quests/soul_war/soul_war_mechanics.lua:643-670`; `data-global/monster/quests/soul_war/goshnars_hatred.lua:136-145`). Recommendation: keep the shared phase counter, player-local remorse count, primary-only damage scaling, and disappearance cleanup as explicit source-backed state; generic outgoing-percent scaling and death-only cleanup do not establish parity.
- **Megalomania phases and timers:** only non-summoned Aspect deaths while the boss is Purple count; each death schedules a fresh Aspect after 5s at the boss position captured at death, and the fourth changes the boss to Green (`data-global/scripts/quests/soul_war/soul_war_mechanics.lua:891-918`; `data-global/lib/quests/soul_war.lua:1401-1421`). That event schedules Blue at +60s, Blue returns to Purple after 7s, and a separate +70s callback changes Green back to Purple only if still Green; under the normal Blue path it is already Purple at +70s, so reproduce the distinct callbacks instead of replacing them with a single 70s Green timer (`data-global/lib/quests/soul_war.lua:585-600,1407-1421`; Purple spawn clears pending phase events and resets the counter at `data-global/monster/quests/soul_war/goshnar's_megalomania_purple.lua:100-115`). Megalomania calls player torment every 10s and white-tile creation every 40s; its tiles revert after 8s, while the torment counter/damage are player-local and use a shared 10s callback gate (`data-global/monster/quests/soul_war/goshnar's_megalomania_purple.lua:117-126`; `data-global/lib/quests/soul_war.lua:1191-1209,1385-1435`). Recommendation: author one phase state machine with captured-position Aspect respawns, separate 60/7/70s events, player torment state, and the same connected tile operation as Malice; do not merge the events or replace them with a generic immunity timer.
- **Cooldown decision:** Wiki revid 1134584 is the current cited rule for 68h Megalomania retry and 20h access-boss retries; both pinned donors and the current Oteryn admission table use 72h for Megalomania (`Crystal data-global/lib/quests/soul_war.lua:450-471`; `Canary data-otservbr-global/lib/quests/soul_war.lua:402-425`; `crates/gameplay/encounters/src/bosses/endgame_entry.rs:134-140`).
