## Donor handler and timer semantics

Both handlers resolve `ChestUnique[item.uid]`, reject an already-set `storage`, and only apply a cooldown if `timerStorage` exists. They draw `math.random(#setting.randomReward)` and copy that entry into `setting.reward[1]` before trying the item handout: [Crystal handler 270-313, 339-349](https://github.com/zimbadev/crystalserver/blob/201189f871d23597b82caf88fd611454a2ddefb8/data-global/scripts/actions/system/quest_reward_common.lua#L270-L313), [Canary handler 153-197, 210-220](https://github.com/opentibiabr/canary/blob/47dfd51f45280a59a1d3e50ba7edd573d7234446/data-otservbr-global/scripts/actions/system/quest_reward_common.lua#L153-L197).

For these six rows, `storage` is set but `timerStorage` is absent. Thus the `time = 24` field is not used by either handler: the initial `storage >= 1` check makes a successfully opened chest stay empty indefinitely. On success the helper writes `storage = 1`; it writes an expiry only when the separately passed `timer` is present ([Crystal 187-229](https://github.com/zimbadev/crystalserver/blob/201189f871d23597b82caf88fd611454a2ddefb8/data-global/scripts/actions/system/quest_reward_common.lua#L187-L229); [Canary 59-105](https://github.com/opentibiabr/canary/blob/47dfd51f45280a59a1d3e50ba7edd573d7234446/data-otservbr-global/scripts/actions/system/quest_reward_common.lua#L59-L105)).

After the initial gate, each `onUse` attempt draws one index from seven, including attempts later refused for capacity or weight; the draw is not a durable per-cycle receipt. Since selection precedes weight/backpack rejection, a refused handout can reroll on retry and no claim state is written on that refusal. The chosen ID/count is also written into the shared in-memory `setting.reward` table before handout. These are donor implementation details, not an accepted production RNG design. The recorded Oteryn requirement is a frozen, auditable draw with durable repeat eligibility per 24-hour cycle ([chest-coverage evidence](../../docs/agents/evidence/chatgpt-quests-chest-coverage.md:154)).
