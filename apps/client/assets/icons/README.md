# Panel icon assets

Lucide 0.468.0, pinned to the revision in manifest.json. Original SVGs and
the upstream ISC license are retained here. Navigation symbols, not game
item appearances or extracted Tibia artwork.

Lossless transparent WebP: 48 px cells in manifest order, eight columns,
four rows. SVG currentColor becomes white; runtime supplies tint.
Rasterizer: CairoSVG 2.9.1, Pillow. Source hashes in the
manifest permit verification independently of rasterizer versions.
