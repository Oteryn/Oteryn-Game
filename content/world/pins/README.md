# World pins

`<slug>.json` pins one reviewed World bundle (`OTERYN_WORLD_PIN/v1`):

| field | meaning |
| --- | --- |
| `digest` | the `OTERYN_WORLD_BUNDLE/v3` digest of the bundle the compiler builds from this tree |
| `project_format_version`, `world_schema_version`, `content_revision` | must equal the identity derived from `project.json` and `manifest.json` |
| `production` | `false`; a production pin on a non-production build fails the gate |
| `entry_start` | `{x, y, floor}`: a walkable, non-blocking base cell inside the World bounds |
| `inputs_digest` | SHA-256 over the git blob ids of the compiler inputs (pin files `<slug>.json` excluded), so it is equal on a branch and on its squash-merged tree |

`<slug>.identity.json` is generated by `world-bundle-compiler derive-identity <root> <slug>`
and is never hand-edited; `<slug>.ruleset.json` is the only hand-written identity source.
`world-bundle-compiler pin-check <root> <out>` (the `world_bundle` job of `game-gate`) checks every
pin, builds the bundle twice and writes `<slug>-<digest>.otwb` and `artifact-name.txt`.
A stale pin is refreshed by running `pin-check` and copying the digests named in its refusal.
