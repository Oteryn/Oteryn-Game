## Implemented speech path

`LoadedNpcCatalogue::from_catalogue` qualifies source voices into the talk book before
the existing catalogue/bundle digest binding admits it. The Channel's existing source owner
cycle drives voice deadlines independently of connection count and does not invoke monster
melee. The review finding about coupling monster melee to loaded voices is accepted: that
unrelated call was removed. Creature/melee scheduling remains with its existing callers. A cycle keeps
the exact runtime movement context, per-actor deterministic think sequences, paused idle
cadences, deadlines and the accepted 256-think/50-ms budget. Late ticks coalesce. Each
critical section processes at most 64 due actors. Removal prunes the actor's state.

Publication rechecks the live NPC census and current position under the runtime lock,
selects local listeners through the existing SAY/YELL geometry and uses the bounded CHAT
queue. NPC YELL retains source case and bypasses player ingress limits. The player/creature
position reader is deliberately not used for NPCs: it rejects that actor class.
Existing connection capability gating owns CHAT egress.

The native play test uses frozen frames generated by the production protocol encoders,
then real `Session::admit` and `run_session`, and checks the formatter displayed by the HWND
chat panel. It does not claim an interactive Windows desktop test on this Linux machine.
