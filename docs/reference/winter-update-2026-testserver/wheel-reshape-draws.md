# Wheel gem reshape draws, Tibia Test Server, 2026-11-14

Character: a Monk with a Greater Spiritualist gem that was not in a vessel. 300 paid draws.

Rules observed:
- Reshape works only inside a temple. Elsewhere the tooltip says "You need to be inside a temple to reshape gems."
- Costs:
  - basic mod 1: 125,000 gold + 1 lesser fragment;
  - basic mod 2: 1,000,000 gold + 2 lesser fragments;
  - supreme mod: 5,000,000 gold + 3 greater fragments.
- No confirmation dialog, and the new mod can be the same as the old one.
- Values differ per mod (crit extra damage 2/8/12%, resistance 1/1.1/1.2/1.5%). This is most likely the Fragment Workshop grade of each mod.
