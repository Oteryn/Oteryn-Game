# Crystal 201189f spawn and raid parity

Crystal 201189f supplies the XML raid membership, clocks and waves. The Old Widow uses the donor’s custom-map registry clock because the record name, two timed announcements and ten-spider wave identify the same raid. The Global XML supplies its boss and cells. The pinned world spawn XML provides exact cells and respawn intervals for all 700 captured points. The map compiler admits 674 points in 386 groups, including the 270 points previously routed to the encounter owner. Scripts own spawns they create outside the world XML. The remaining 26 world points are retained as unsupported source behavior: five Cobra Assassin or Cobra Scout placements require Cobra Flask behavior, and 21 Quara Kindler or Rootthing Conservator placements require faction targeting.

The two Crystal Orc registrations share the same Lua body after the registration name. The Oramond XML spells the Dark Trails boss “The Ravenger.” The donor monster file and the existing Dark Trails binding identify it as The Ravager.
