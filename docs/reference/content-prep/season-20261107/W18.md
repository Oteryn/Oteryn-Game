## Reproduction

The committed checker reads complete donor XML and protobuf appearances, then
compares targets to EXACT Crystal bindings and canonical Item definitions:

```sh
python3 tools/content-migration/audit_house_decoration_sources.py \
  --crystal /path/to/crystal-201189f \
  --canary /path/to/canary-47dfd51f \
  --output /tmp/house-decoration-source-closure.json
python3 -m unittest discover -s tools/content-migration \
  -p test_audit_house_decoration_sources.py -v
```

`house-decoration-source-closure.json` beside this note is generated by that
command. It records source SHA-256 hashes, canonical input hashes and six
unavailable edges (three per donor). It includes no donor XML, DAT or assets.

The checker tests require missing targets to remain unavailable even when a
reciprocal sibling exists, distinguish appearance presence from canonical
identity, and accept a fully closed graph.
