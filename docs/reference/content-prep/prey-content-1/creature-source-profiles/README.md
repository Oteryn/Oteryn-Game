# Five missing Prey creatures: source reconciliation

All five now have explicit wiki-sourced reference profiles, linked to their client15.30 identities. Full pinned TFS1.6 XML source definitions were recovered for Elder Forest Fury and Undead Jester; their element/attribute trees are retained without silently converting engine speed, item IDs or old combat values into native facts. TFS is supplementary OTS_HYPOTHESIS_ONLY evidence, not an approved runtime source or proof of current Global behavior.

Berrypest, Furious Fire Elemental and Nightslayer have sourced partial profiles. No complete source registration was recovered in this bounded search. The source inventory covers1723Canary monster files and all3526Crystal monster files across both datapacks at the current pinned branch heads; no exact registration or full-name mention for these five exists there. It does not claim internet-wide absence.

Known disagreements are recorded per creature: Berrypest pushability; Elder Forest Fury attack/debuff descriptions and old TFS XP/charm values; Furious Fire Elemental damage/mitigation; Nightslayer damage/mitigation; Undead Jester mitigation, summon identity, pushability, charm points and old loot table. Source strings and uncertain bounds are preserved. No attack schedule, probability or native identity is fabricated.

The profiles are reference evidence, not validator-ready native Monster bundles. Exact native materialization requires those unresolved mechanics and bindings to be qualified first. Cake Golem's separately validated partial bundle remains under ../cake-golem/.
