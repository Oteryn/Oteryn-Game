# Full pinned monster spell authoring import

All tracked monster files and script packs from Canary 99902524 and Crystal ff7ede59 are retained as distinct donor populations. Converted bundles are genuine existing authoring-schema Creature/Behavior/Presentation plus Ability/Effect/Formula candidates. Mapped source slots preserve source order, interval and chance through the converter. Source parameter tables and exact Git blob/SHA-256 provenance remain in split per-source slot files.

`mapped` does not mean admitted native Game gameplay. Identities remain source scoped; full monster AI and custom encounter callbacks are not enabled. Historical converter engine rules need current parity qualification. External published attack observations are bound separately by the monster-reference report; absent chance/interval/effect values remain unknown.

`registration-capture-closure.json` distinguishes lexical declarations from actual sandbox-captured registrations, including source-disabled examples and opaque entries. `remaining-blockers.json` lists unresolved individual spells, invalid donor creature fields, and source-faithful partial extraction of tables whose top-level encounter setup cannot run outside the engine. SoulWar interval 7 is read from the exact pinned source library; no Zone positions, Storage ids, world state or gameplay callbacks are fabricated.

Source-input Lua/XML/DAT snapshots are local reference inputs and excluded from the review archive. The split source profile and slot files plus all converted JSON bundles are included. The combined convenience arrays are redundant and excluded.
