## Owner correction

Newhaven/Targuna is no longer a standalone investigation programme or a recurring prerequisite for every Content/World increment.

The bounded corridor served its intended purpose as the first real Reference-shaped fixture for source census, evidence discipline, source/import mapping, format measurements and later runtime/client qualification. Continuing to open broad tasks around the same geography after those questions are answered would convert a useful fixture into programme drag.

From this policy forward:

```text
Newhaven/Targuna = bounded regression / qualification fixture
Newhaven/Targuna != Content/World product scope
Newhaven/Targuna != permanent global blocker
#511 != permission for recurring broad capture/discovery work
```

This correction narrows execution churn; it does not weaken accepted evidence rules, runtime safety, target-date honesty or the intended full-world architecture.

## Evidence retained and frozen

Retain, do not rediscover:

- merged #525 Phase-A source census and its exact pinned source/digests;
- protected Game-owned fullworld producer and reconstruction tooling;
- accepted D1 Content source/owner semantics from #504/#641;
- retained official-client Newhaven-area reports harvested from historical Platform PR #1006, including the 2026-08-12/13 build-bound observations already recorded in Game evidence;
- all existing classifications that distinguish migration/OTS evidence, official-client observation, target-cut continuity and unresolved fields.

#525 Phase A remains migration/source evidence. Post-target captures remain post-target observations unless exact continuity to the 2026-07-28 target is established. Nothing in this policy promotes legacy/OTS coordinates, collision, stack order or an August capture to July target truth.

## Final allowed corridor evidence action

At most one bounded read-only comparison of the already-retained official-client sample against the overlapping protected #525 source evidence may be consumed if it has not already been terminally summarized.

That comparison may only:

1. bind exact retained capture provenance/build/date and #525 producer/source digests;
2. normalize the retained `(x,y,z,order,raw field)` records without renaming unknown fields;
3. compare only coordinates/ordered cardinality/identifier membership for which both sides retain evidence;
4. classify each compared atomic field as `PROVEN`, `OBSERVED_POST_TARGET`, `DERIVED`, `UNKNOWN` or `CONFLICT` as applicable;
5. produce the smallest explicit list of unresolved target-sensitive fields.

It must not:

- launch the Tibia client or require a private host;
- request another general Newhaven/Targuna capture;
- expand source windows merely to make the map prettier or more complete;
- run a full-world scan;
- create a new parser/importer/comparison framework;
- chase continuity for every cell, stack or object;
- block generic Content model/import/runtime work on unrelated unresolved target fields.

If the retained comparison cannot prove the 2026-07-28 value for an atomic field, preserve `UNKNOWN`/`CONFLICT`/`OBSERVED_POST_TARGET`; do not start a new broad evidence expedition just to eliminate the label.

## Exit condition

The corridor evidence lane is terminal for programme-planning purposes when the retained comparison above is consumed or when the current live record already contains the same bounded result.

After that point:

```text
REFERENCE_CORRIDOR_STANDALONE_DISCOVERY: STOP
NEW_NEWHAVEN_BROAD_CAPTURE: FORBIDDEN_BY_DEFAULT
NEW_TARGUNA_BROAD_CAPTURE: FORBIDDEN_BY_DEFAULT
FULL_CORRIDOR_CONTINUITY_SWEEP: FORBIDDEN_BY_DEFAULT
SOURCE_WINDOW_EXPANSION_FOR_COMPLETENESS: FORBIDDEN_BY_DEFAULT
CORRIDOR_ROLE: REGRESSION_FIXTURE_ONLY
```

Unresolved critical data needed by no current executable slice remains deferred. Unresolved data required by a concrete current executable slice fails only that capability/placement/promotion; it does not automatically block the whole world model, importer, compiler or unrelated playable work.

## Exception trigger

A future bounded evidence task against this geography is allowed only when all conditions are true:

1. a current executable milestone names one exact atomic field or behavior as its blocker;
2. the existing retained evidence is insufficient for that exact field;
3. the requirement cannot be satisfied by an already accepted source, another representative fixture, or a declared Oteryn difference;
4. #162 issues an exact bounded task for that field/behavior only.

The task must return one discriminator or remain `UNKNOWN/CONFLICT`. It must not reopen #511 as a broad programme or reactivate the entire corridor acceptance matrix.

## Targuna disposition

Targuna is not independently researched merely because it was paired with Newhaven in the original corridor gate.

The existing Targuna Phase-A corpus remains a retained source/regression fixture. Additional Targuna target evidence is acquired only when a concrete playable transition/service/re-entry milestone actually exercises a Targuna-specific fact that is unresolved and material.

No requirement exists to make every Targuna tile, NPC, transition or stack target-proven before Content/World implementation can progress.

## Programme priority after fixture freeze

The default execution path is now:

```text
CW2 bounded source-identity adapter
  -> CW3 typed Reference successor model/linker
  -> D3 real-batch bundle measurement
  -> CW4 current-owner local-object runtime composition
  -> CW5 native client projection/reconciliation
  -> CW6 real playable qualification
  -> expand catalogue/world through the same pipeline
```

Where Gate-C or another exact authority/capability condition prevents mutation, continue only path-disjoint preparation that directly shortens one of those implementation steps. Do not substitute another corridor/capture investigation because code mutation is temporarily unavailable.

Once the generic pipeline is proven on the corridor fixture, the next world-data work should broaden to the next product-relevant region/content family, not deepen Newhaven/Targuna research without the exception trigger above.

## Required routing behavior

All Content/World prompts and coordinators must treat this policy as an execution delta:

- #511 historical material remains evidence, not recurring discovery authority;
- `Oteryn: ref world` may investigate a specific future blocker, not restart broad corridor research;
- `Oteryn: content world import` consumes the fixture as input/regression evidence and moves on;
- `Oteryn: content world architecture` must not require complete target proof of the corridor to decide unrelated generic model/format questions;
- `Oteryn: content world runtime/client/qa` may use the corridor as a deterministic test vector;
- unknown target-specific values remain fail-closed at their exact use point.

This policy does not claim full Tibia Global parity for Newhaven or Targuna. It deliberately prevents parity uncertainty in one bounded fixture from becoming an endless prerequisite for building the product.
