# Game prompt evaluation extension

Game adopts the evaluation standard at the immutable META revision in `META_AGENT_POLICY_BINDING.json`, path `docs/agents/policy/PROMPT_EVAL_STANDARD.md`.

For a material Game prompt change, verify the lifecycle registry, actual root/nearest instruction delivery, central task-delta validation, domain acceptance behavior and applicable repository checks. Include adversarial cases for scope, stale live locators and protected Game invariants. Text lint or a binding alone does not prove safe behavior.

Report source/context volume separately from measured model or API usage. Do not claim token or cost savings without telemetry.
