# Reusable agent prompts

These prompts are execution contracts for recurring Oteryn v2 programmes. They do not replace trusted-base governance, live task checkpoints, accepted ADRs/contracts or live PR/CI state.

- `OTV2_GLOBAL_ARCHITECTURE_DECISION_COORDINATOR.md` — continue the staged global architecture decision programme autonomously, beginning with the current canonical foundation next action.

Before reuse, evaluate the selected prompt against `../PROMPT_EVAL_STANDARD.md` and verify all repository state named by the prompt against live GitHub state.
