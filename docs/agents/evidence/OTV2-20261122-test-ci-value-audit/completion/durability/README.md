The valid maximum remains useful; the decision/body and descriptor bounds exercise different conditions. This is not a claim that the entire suite would miss the mutation. No mutation of that production guard has been executed in this pass.

**RECOMMENDATION:** qualify the private authority grammar/length validator with fixed 128/129-byte inputs, or demonstrate pre-retention rejection before any holder acquisition. Keep the integration mismatch case and positive registration. If the integration test continues to claim no retention, add an independent before/after read of the relevant history/floor state. Current error-only assertions do not by themselves establish that stronger claim.
