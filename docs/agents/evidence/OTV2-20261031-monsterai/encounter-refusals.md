## Regression gate

`crates/gameplay/dispatch/src/lifted_tests/creature_encounter_refusals_tests.rs` loads the actual manifest through `NativeGameplayInput` and the existing content qualification path. It compares the exact set of creature key, attack index, Ability key and Encounter key with all eighteen expected entries. For each entry it verifies `SpellSource::from_native` and `ComposedSource::from_native_parts` return `UnsupportedShape`, and the source Item owner does not claim the Ability. A missing entry, newly introduced Encounter attack, or changed binding fails the test. This is a refusal/admission regression, not an execution parity claim for the excluded scripts.

Run with the existing `OTERYN_FULL_SPELL_TEST_MANIFEST` value and:

```bash
cargo test --locked -p oteryn-gameplay-dispatch --all-features --lib monster_actual_encounter_attacks_remain_eighteen_explicit_refusals -- --ignored --nocapture
```

The test follows the existing explicit full-manifest opt-in convention. An ordinary default run reports it ignored and is not evidence that this gate passed.
