## Recovery register

`CharacterRecoveryStore` pins an opened directory descriptor, checks configured scope/issuer IDs and service ownership, and rejects a writable or wrong-owner parent. All record/lock/temp operations are relative to that descriptor; final symlinks are refused. Reader seals hold the process-shared file lock and in-process generation read guard for their lifetime; transitions hold both exclusive guards. A new generation uses checked successor arithmetic and a canonical UUIDv7 event. Fresh authorization requires a missing register; recovery requires the exact predecessor; an ambiguous rerun reconciles only the exact retained successor/event/issued-at/scope/issuer tuple. The predecessor digest binds canonical prior bytes.

Records are bounded to 1024 bytes and must round-trip to exactly the canonical encoding. Zero generation, invalid succession, non-RFC UUIDs, inconsistent genesis digest, malformed fields, noncanonical numeric/hex encoding and wrong identity fail closed. Replacement exclusively creates a temporary file, assigns ownership through its descriptor, writes and synchronizes it, atomically renames it, then synchronizes the pinned directory. Errors are surfaced; a failure after rename may have advanced the register, which is why exact retained-event reconciliation is necessary.

The real operator (`apps/game-server/src/bin/oteryn-game-ops.rs:512-638`) retains the request before mutation, reuses its event/time after an ambiguous result, checks repeated restore parameters, keeps the transition seal alive across the database reconciliation await and distinguishes generation conflict from an ambiguous outcome. The API itself does not silently lower a generation. All package tests were checked for restart, path replacement, exact replay/conflict, malformed/nonregular records and ownership/mode assertions. Actual kernel/filesystem crash behavior and the complete database transaction population remain separate unexecuted scopes; this package completion does not claim a full durability audit.

The parser's index arithmetic is bounded by its accepted raw length and private buffer sizes. An escaped duplicate key is checked after decoding. A renamed retained directory cannot redirect later operations. Missing/malformed recovery state cannot bootstrap ordinary runtime authority. A replay with another event cannot be mistaken for the same transition. A hostile process running as the trusted service account is not established as an unprivileged remote caller.
