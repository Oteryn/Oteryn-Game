## Exit criteria

- Capture complete: every scoped Git-tree text blob available with verified bytes.
- Representation complete: every relevant source construct retained faithfully in
  source schemas; explicit opaque/unmapped counts remain failures of semantic1:1.
- Native complete: separate runtime ownership, never inferred from source capture.
- Wiki research allowed: independent donor representation completeness proof.
