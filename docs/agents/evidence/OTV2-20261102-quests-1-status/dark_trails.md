# Dark Trails — stan partii 1

## Zakres i status AUTHORING

Ta notatka opisuje prywatny wkład `dark_trails` do PR #2845. Nie kwalifikuje pośredniego commitu ani całego questa jako grywalnego. Rejestracje i aktywne callbacki trafiają do końcowego wspólnego commitu; wspólny helper ma osobny wcześniejszy commit. Zasady publikacji i testów: [ANSWER o rozdziale commitów](https://github.com/Oteryn/Oteryn-Game/pull/2845#issuecomment-6590727985), [ANSWER o prywatnych headach AUTHORING](https://github.com/Oteryn/Oteryn-Game/pull/2845#issuecomment-6591052733).

Donor główny pozostaje przypięty do `zimbadev/crystalserver@201189f871d23597b82caf88fd611454a2ddefb8`. Numery A poniżej zachowują kolejność 40 wierszy z raportu `docs/agents/evidence/OTV2-20261102-quests-1-20261102.md`. Wszystkie wskazane warunki i efekty pochodzą z przypiętych plików, nie z dopowiedzeń Global. MediaWiki API zwróciło HTTP 403; bieżące porównanie Global pozostaje `NIEZNANE/API403`, zgodnie z [QUESTION GLOBAL-API](https://github.com/Oteryn/Oteryn-Game/pull/2845#issuecomment-6589173099) i [ANSWER §1](https://github.com/Oteryn/Oteryn-Game/pull/2845#issuecomment-6589524728).

Przy liczeniu **pełnych istniejących wierszy A** rekomendowana klasyfikacja to **AUTO 0 / RĘCZNIE 40**, zamiast AUTO 5. To nie usuwa wykonanych danych ani kodu. Wiersz wymagający brakującego efektu lub niepotwierdzonej kwalifikacji mapy nie jest w całości automatycznym importem. Nie mnożymy liczby kroków przez rozbijanie gotowej i wstrzymanej części jednego wiersza.

## Walidacja i odtwarzalność

Potwierdzone przez integratora wyniki z kompletnego roboczego drzewa AUTHORING: **12 testów modelu Dark Trails PASS**. To zapis wykonanych prób, nie wynik walidacji SHA tego prywatnego commitu. Końcowe `fmt`, `clippy`, `test`, kontrole treści, indeksów i pinów muszą zostać wykonane na zamrożonym końcowym SHA zgodnie z [ANSWER](https://github.com/Oteryn/Oteryn-Game/pull/2845#issuecomment-6591052733). Wyniku trwających prób PostgreSQL nie uznaje się w tej notatce za PASS.

Dane tego questa odtwarza repozytoryjny generator:

```text
python tools/content-schema/quest-authoring/quests_batch_one --crystal-root <repo-Crystal-z-przypiętym-commitem> --output . --quest dark_trails --check
```

Generator czyta `git show 201189f871d23597b82caf88fd611454a2ddefb8:<path>`, sprawdza przypięty census NPC i nie korzysta z roboczych zmian donora. Moduły innych questów są importowane dopiero w odpowiedniej gałęzi; prywatny commit nie zależy od jeszcze nieopublikowanego buildera innego questa. Pełny donorowy dialog zostaje w danych, także dla gałęzi wstrzymanych. Zachowanie tekstu nie uruchamia takiej gałęzi.
