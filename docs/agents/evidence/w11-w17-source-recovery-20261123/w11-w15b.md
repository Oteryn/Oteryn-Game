## W15b: distinguish quantity from fluid subtype

[Crystal chest.lua:1489–1507][crystal-chest] places UID6119 at
`(31977,32209,12)`, with bag2853 containing pan3466 x1, snowballs2992 x4 and
`{2874,1}`. Its comment calls the vial milk. The other chest, UID6118 at
`(31973,32209,12)`, contains sandals3551 x1, stones1781 x5 and gold3031 x50.

The source path is unambiguous:

1. [`Container:addItem`][crystal-container] treats its second parameter as
   `count/subType` and forwards it to `Item::CreateItem`.
2. [The Item constructor][crystal-item] stores that argument as `FLUIDTYPE`
   for a fluid container.
3. [The enum][crystal-fluids] assigns water=1 and milk=9.

Thus the literal donor gives water, not an unspecified or empty vial. The
numeric value 9 is the Crystal/Oteryn representation; this does not claim
CipSoft uses the same internal number. Selecting milk is an explicit source
reconciliation, already named `WIKI_MILK_OVERRIDES_DONOR_WATER` in Oteryn.
