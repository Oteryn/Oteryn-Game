# W17 — Tibiadrome source recovery, 2026-11-23

## Scope and result

Repository inspection: `4f13511ca9ec3fb152f11299bb5cf7c71de16c41` (staging
base). This is retained evidence, not a new ruleset decision or production
admission. Target game version: **15.30**.

**PROVEN:** the five monster names, group-size counts and nine modifier policies
are already recorded in the accepted ARENA1 decision and implemented in existing
policy owners. W17 is not missing an entire wave design. **UNKNOWN:** complete
native creature profiles and an admitted battle room. The actual dispatch spawn
caller still cycles Svargrond opponents behind a production refusal; adding only
monster names or opening that refusal would not implement Tibiadrome.

The second capture now connects **all five names to looks 1422–1426** through
original named gameplay and rendered client artwork. The retained 15.30 catalog,
raw appearance records and all six compressed sprite sheets agree with the
inspected assets. A pinned TibiaMaps/video reconstruction also identifies
**252 battle cells on Thais floor 12**, the lever and five waiting pads.
These are useful source inputs, not complete native Creature/World admission.

An executable, offline source producer and its generated packet now retain and
verify those inputs. It emits no incomplete Creature records. A separate
**CONFLICT** was found: original 2023 gameplay skips 1, 2 and 3 waves after fast
clears; existing Oteryn progression advances only one. Exact thresholds, skipped
wave scoring and continuity of that behavior to 15.30 remain **UNKNOWN**.

### Nine modifier policies

Percent HP damage uses **current** HP. Values are the accepted A4 policies,
cross-referenced to M; Chebyshev radius 1, deterministic draws and related
implementation choices must retain their Oteryn-decision provenance.

| Modifier | Trigger / timing | Effect |
|---|---|---|
| Somersault | Each melee attack, **15%** | Move monster next to the farthest participant. |
| Going Down With Me | Monster death | **40%** current HP; last-hitter-centered area, radius **1**. |
| Exploding Corpses | Monster death | **25%** current HP; corpse-centered area, radius **1**. |
| That Escalated Quickly | Monster HP **<25%** of maximum | Damage uses **w+5**; no HP increase/heal. |
| The Floor is Lava | Every **15 s**; mark **100** tiles; resolve **3 s** later | Standing participant loses **60%** current HP. |
| Beam me Up! | Every **15 s**; **100** tiles; **3 s** warning | Teleport standing participant to a free walkable room tile. |
| Tanked Up | Every **15 s**; **100** tiles; **3 s** warning | Drunk for **10 s**, incoming damage **+10%** during it. |
| Sown Sorrow | Seed every **20/17/14/11/8 s** for group size 1/2/3/4/5 | Step within **6 s**; otherwise all participants fear **2 s**, incoming damage **+15%**. |
| Bad Roots | Same seed periods and **6 s** deadline | Otherwise all participants root **3 s**, incoming damage **+25%**. |

A4 freezes seed frequency to **admission group size**, even after a defeat. Tile
overlap resolves once per participant per pulse. R explicitly leaves overlapping
10/15/25% bonus algebra and cleansing/bonus lifetime undecided; the mechanics
fixture's behavior cannot approve those choices.

### Reproducible producer and actual reuse boundary

The producer accepts only the bounded immutable packet. Every nested field must
match its source-derived body: unknown fields, extra cells, swapped looks,
invented thresholds and `runtime_admission=true` refuse. Duplicate JSON keys
also refuse. The `check` command replays all raw source validation and compares
the exact output bytes; it never repairs or overwrites drift.

Store the eight map files in one input directory as
`target-floor-11-map.png`, `target-floor-11-path.png`,
`target-floor-12-map.png`, `target-floor-12-path.png` and the equivalent four
`current-` names. Obtain each `data/floor-*-*.png` at its packet commit through
the normal public repository route. `--sprites` points to a directory containing
the six original compressed sheets named in the packet. The retained shard,
manifest and catalog default to their repository paths; explicit paths support
a sparse checkout without rewriting content inputs.

```sh
python3 tools/content-migration/tibiadrome_source_profile.py capture \
  --maps /path/to/pinned-maps --sprites /path/to/client-assets
python3 tools/content-migration/tibiadrome_source_profile.py check \
  --maps /path/to/pinned-maps --sprites /path/to/client-assets
```

hashes. This verifies frame identity, not a fresh automated semantic reading.

`--catalog`; `--output` selects an explicit source-packet destination. Both
