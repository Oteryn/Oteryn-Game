## Outcome

Four free self-heal starter bundles are added as data: Magic Patch `exura infir`, Bruise Bane
`exura infir ico`, Wound Cleansing `exura ico`, Ultimate Healing `exura vita`. Each is generated by
`convert_spells.py` from the pinned Canary 99902524 and Crystal ff7ede59 sources and reproduces
byte-exact. `V1_BUNDLES` is NOT changed: the V1 expansion was dropped in favour of
SPELL-BOOK-ACTIVATE-1 (D577 sends the full 246-spell book to the default node), because
`SpellBook::canonical` re-sorts indices by key (7 spells would move the existing indices 1-3) and the
tests that hardcode them belong to SPELL-LOCK-1 and ATTACK-1b.

## Architecture and source of truth

- PROVEN: only `party_buff` is read by the S7 reader; the 246-entry catalog is compiled only when
  `OTERYN_NATIVE_GAMEPLAY_MANIFEST` is set; the default node boots `v1_spell_book()`.
- PROVEN: cast-wire contract §6: V1 casts only self heal and condition removal.
- PROVEN: the starter bundles reproduce byte-exact from the pinned sources (`diff -r`, locally).
- Closure data (`codex/spells-source-closure-20261003`, draft #1755) is reference evidence only; its
  private schema `...source-complete:candidate:2` is not adopted (SPELL-NPC-MAP-0 §2). All 475 of its
  candidates carry `authoring_contract_extension_pending=true`, so none could be admitted as is.
- Third-party spell text: `library_text` in the new `spell.json` files is the same donor-derived
  field the 9 existing starter bundles already carry; no new notice file was added.
