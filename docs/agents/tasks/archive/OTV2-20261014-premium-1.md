## Result

- One Premium fence. The PREM-1 consumer (`premium/mod.rs`, `durability/premium_fence.rs`,
  migration 0029) is the only Premium read of Game. The spell candidate fence is retired and
  deleted: its adapter and mTLS pull (`gameplay_transport/spell_entitlements.rs`), its durable
  consumer (`durability/spell_entitlements.rs`), its ABI (`durability/spell_premium_abi.rs`) and
  its transport-only pull `native_admission_source::read_premium_snapshot`, which had no caller.
- `domain::premium::PremiumGate`: the one value a Premium-gated decision reads. It is closed by
  `Default` and `PremiumGate::CLOSED`. Only a fence read opens it (`pub(crate) from_fence_read`),
  from `PremiumConsumer::premium_current`, which is true only for `CurrentAuthority`. `require()` refuses with
  `PremiumRefusal::NotCurrent`.
- `PremiumConsumer::current_premium`: the same classification under one lock, plus the authority
  revision and the benefit end, `min(effective_until, authority_valid_until, refresh_after)`.
- `SpellPremiumCoordinator` holds the consumer and the registered trusted clock owner. `serve.rs`
  builds it, and the node's `PremiumRefresher` pulls into its consumer, so spells and every gate
  read the fence that admission pulls, fences and proves. A spell view reads the consumer live at
  every use: a failed pull, a revocation, a release, a lapsed lease or a lost clock closes views
  already issued. The projection is current authority only, valid in the owner's monotonic domain
  until the benefit ends, measured from the upper bound of the trusted window.
- Gate API for MAGIC-CAST-1 §4.6, PROG-ADV, HOUSE and GUILD: `ComposedFreshAdmission::premium_gate(account)`
  and `::session_premium_gate(session)`. The second resolves the account the session was
  admitted for from the node's Premium registrations.
- Chat yell: `chat_speak` reads `session_premium_gate` into `YellGate.premium_current`
  (previously hard `false`).
- Fail closed: an unknown account, any class but current authority, no trusted clock owner, a
  lost clock, a failed pull and a restart all read Free.
- High-risk authority/recovery qualification: read-only authority gate. No durable write, no
  migration, no fencing, no wire change. The gates only narrow (fail closed); they never grant.
