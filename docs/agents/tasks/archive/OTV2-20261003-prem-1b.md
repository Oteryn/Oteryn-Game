## Outcome

- **Client (scope 1, 2).** `premium::client`: `POST /v1/premium/snapshot` with the exact §3.1
  body (at most 256 bytes), reqwest over rustls with mutual TLS: the client identity and the
  Platform CA from `OTERYN_PREMIUM_CLIENT_IDENTITY_PEM` and `OTERYN_PREMIUM_PLATFORM_CA_PEM`
  (files), the origin from `OTERYN_PREMIUM_SNAPSHOT_URL`; only the configured CA is trusted;
  HTTPS only, no proxy, redirects off, 5-second total timeout, body read capped at 1,024 bytes.
  Only a 200 `application/json` body is returned. No configuration: no client, Premium reads
  Free. The nonce is 128 bits from the TLS provider's OS-seeded CSPRNG, as the gameplay seam's
  session identifiers, fresh per request and retry.
- **Failed-pull state (scope 3).** `PremiumConsumer` takes a `PullTicket` when a pull starts. A
  failed pull (transport, status, content type, size, malformed, stale) marks the account
  `AUTHORITY_UNAVAILABLE`; only a successful ingest of a pull started after the latest failure
  clears it, and a failure or quarantine from a pull started before the latest proof changes
  nothing. REVOKED, EXPIRED, NOT_YET_EFFECTIVE and every conflict still win. In memory only.
- **Scheduling (scope 4).** `premium::refresh::PremiumRefresher`: one task per online account
  loads the durable fence, pulls at once, then at each `refresh_after` and never sooner than 60
  seconds after a success; failures retry with capped (60 s) exponential backoff and equal
  jitter, a 429/503 `Retry-After` honoured within the cap. Reconnects coalesce onto the one task,
  so one request at most is in flight. `admit` returns at once; `release` cancels.
- **Call sites.** `gameplay_transport/mod.rs`: the composed admission authority owns the
  refresher; a committed fresh admission and a committed resume call `admit`, and the grace
  release of the session calls `release`. No Premium read exists yet (PREM-2..5).
- **Test producer (scope 5).** `premium::test_producer` (`cfg(test)` and the integration test
  only): a loopback mutual-TLS HTTP/1.1 server with its own test PKI that serves exactly §3.1 and
  answers each request from a scriptable handler (status, headers, body, delay).
- **PREM-1a fixes (scope 6).** The decoder accepts the producer `NONE` form (null interval and
  entitlement, lifecycle 0) and rejects a null interval elsewhere; the evidence fingerprint
  covers `refresh_after`; a `refresh_after` outside the authority interval is Malformed.
- **Durable semantic conflict and audit (scope 7).** Migration 0057 adds
  `game_premium_account_conflict` (keyed by account, first detection kept) and
  `game_premium_security_audit` (unique per account, kind and revision), insert-only for the
  runtime role, with update, delete and truncate rejected. Every contradiction (current or
  historical revision, lifecycle regression) and every unsupported response writes both in one
  transaction, serialized per account by an advisory lock, before the outcome returns; the fence
  view reports a conflict row as conflicting, so a restart, a `release` or a consumer that never
  loaded still denies. `snapshot::validate` compares the compatibility record and the lease
  policy only after every type, value-form, closed-`NONE` and structural check.

## Decisions and stated interpretations

- **Migration number.** The packet needs one lease (`<lease>`); the allocation said none. The
  control plane leased 0057 (0033-0056 are leased elsewhere).
- **Unknown members.** Under the v1 schema an unknown member is Malformed; it is checked after
  the compatibility comparison, so a later version that adds members stays Unsupported.
- **`premium_entitlement_ended`.** It reads only the kept evidence; a conflict or failed pull no
  longer forces it false (§3.1: "leaves `premium_entitlement_ended` unchanged"). This replaces
  PREM-1a's behaviour.
- **A response bound to another request** is now a failed pull (§3.1), so the PREM-1a restart
  case expects `AUTHORITY_UNAVAILABLE` until the next successful pull.
- **`NONE` stores a zero interval** (`effective_from_us` = `effective_until_us` = 0), which the
  0029 columns accept; no other path reads it.
