Packet: `docs/architecture/reviews/OTERYN_GAME_ARCH_ERROR_CODES_2026-10-05.md` §2.2 with §1.1, §1.4, §1.5 and §1.10.

Every Node process writes the §1.5 diagnostic line. `process_start` is always the first line and carries `build` (`version+sha`). A panic writes exactly one `E4001 PANIC` line. `OTERYN_LOG` filters info and debug lines only.
