## Result

- The map loader keeps the bundle's validated spawn family (`map::load_spawns`); `check` stores it on the checked bundle and the booted `BundleWorld` (format v3 spawn frame, already decoded and validated by `oteryn-world-bundle`).
- `table_activation_spawns` turns the family into the carrier's per-point source seam (#2002, `ActivationSpawnSourceFacts`): one runtime source per bundle source (Codex P1 4243711197), its points in authored order, each with cell `(x, y, -floor)`, its own respawn delay, creature key, initial health and blockable flag; occupancy retry 5,000 ms per source. Points of a creature whose period is not `All` are outside the activation set; a source left with no point is not activated. Each creature's profile is resolved once.
- A bundle World now realizes those sources at Channel activation, before the listener binds (`realize_bundle_spawns`). The initial health of a creature is its served definition's maximum health; a creature the active content does not serve refuses readiness (`creature spawn realization`). The fixture World keeps the D116 source.
- Merged with main after SPAWN-CEILINGS-1 (#1984). The carrier's fixture-era 16 sources / 4 cells are gone (Codex P1 4241672767): activation is checked against `CREATUREAI0-RL-01` to `-03` and the carrier's player headroom.
- `CREATUREAI0-RL-14` (Codex P1 4241840141): boot begins the activation once (`begin_activation_spawn_sources`, every ceiling checked, nothing admitted) and realizes it with `realize_activation_spawn_window`, at most 4,096 points per 50 ms owner window, on a boot-local monotonic clock that waits for the next window boundary between windows (`realize_activation_paced`). A shutdown requested meanwhile stops boot before readiness. The boot event reports `windows=N`. Tested: 8,253 points realize in 3 windows over at least 100 ms; a cancelled boot stops after the first window.

## Resolved blocker: RL-02 at the reference bundle

- The carrier used to hold one creature and one respawn delay per spawn source, so this task split each bundle source into runs of points sharing both: on the pinned pre-production bundle (`5c32d7ac...`: 51,078 sources, 82,673 active points, 9,468 sources mixing creatures or delays) that gave 70,206 carrier sources, above `CREATUREAI0-RL-02` (65,536).
- Resolved by carrier dependency #2002 (merged to main): `begin_activation_spawn_sources` takes one source per bundle source with per-point creature, delay, initial health and blockable. Main is merged into this branch and boot uses it. Tested: a family of the bundle's shape (51,078 sources, 82,673 points, 31,595 mixed sources) stays 51,078 runtime sources and realizes in 21 owner windows.
