## Outcome

Implemented the supplied `PROMPT_20_prey_difficulty.md` in the existing Prey
owners. Each slot has a persistent five-tier choice, a level allowance, a
configurable 9/12-creature list, durable daily offer exclusions, and a
server-priced Pick Again action. Prey time follows the selected race, with
both defense policies implemented and V2 configured. The native client
exposes the tier controls, expanded grid and confirmed purchase. Permanent
Store delivery, transactional end-history measurements and read-only
control-plane views are implemented.

Classification and slot values are generated from source content. The
deterministic Rust tool calls production physical combat, RNG and minute
clock owners and emits the 15-case comparison and 776 per-creature
estimates. The complete reports are `docs/balance/PREY-TIME-SIM-2026-11-01.md`
and `docs/balance/PREY-SLOT-VALUE-2026-11-01.md`.

Implementation completion does not grant release approval. The eleven questions
below remain open, the production expansion offer is disabled,
and the PR remains a draft. No review request, deployment or merge into
protected main was performed.
