The quest-owned authored binding routes the City of Gold idol through the existing carried quest reward owner to unlock Ancient Aucar base. The authenticated item spend, outfit grant and redeemed stage commit together. Crystal supplies item ID 40578, looks 1597/1598 and one-item consumption only on success. The carried selector excludes dialogue routing. The donor's green effect and duplicate feedback still need a carried reward presentation route.
