## Accepted scope and implementation

Extend the existing Hazard, Quest, encounter, Character, appearance, NPC, payment
and MINT authorities. The shared boss/activity owner remains the sole encounter
admission authority. W11 follows the requested Global/Wiki priority and the
explicit owner decisions below.

- Primal unlock is an atomic native death-receipt descendant: contributing group
  minimum, selected maximum, cap 12, zero-XP support, retained replay and current
  session/lease/scope/node fences. Existing Hazard command 169 remains the selector.
- Source-qualified Hazard monster melee, HP spells and composed HP callbacks share
  one player critical window. Positive damage stages round upward. Mana drain,
  healing, conditions without primary HP damage and stale source frames do not
  acquire Hazard HP effects. Inherited coefficients remain marked provisional.
- Soul War persists five distinct flags, the first-taint fourteen-day clock,
  per-recipient exact `209^n/200^n` XP, task/cleanse/report NPC commands, verified
  final completion, a retained uniform item choice and source-chest delivery
  through the existing MINT owner. Final victory can cross expiry; entry owns the
  full-chain check. Revenant grants a base appearance entitlement once.
- Rotten Blood uses the existing Quest callback for source altar consumption,
  source NPC mission and acknowledgement, the existing coins/Bank/fee owners for
  the 5,000,000 detour, four persistent child flags, regular/final taints, retained
  cleansing clocks, final completion and a once-only base Decaying Defender grant.
- The shared terminal consumer accepts only an authoritative unsuccessful encounter
  result. It retains one deterministic flag pair, the complete participant roster,
  current fences and atomic descendants. Expired Soul participants have explicit
  no-op outcomes; replay never resets a later cycle.
- This change adds exactly the source-backed Bloody Tear 32594 profile through
  the existing content generator.
  Generated manifests are regenerated by repository tools. No corpse capacity,
  materializability, map qualification or selectable outfit mapping is invented.
