# Quest component Source data

Local donor-first authoring for248 previously unjoined script components.
Boss83/events75/other90 assignments are disjoint; generators preserve exact Source
witnesses, AST/control-flow order, unknown expressions and configuration values.
The joins module provides a conservative full352 Quest/component crosswalk.
The dialogue module supplies a bounded12-file NPC/helper source supplement.

From the quest-authoring directory:

```sh
python quest_component_authoring.py --check
python -m unittest test_quest_components
```

The normal quest_donor_source_authoring.py replay also verifies this entire batch.
All builders work offline against relative corpus CAS and portable AST shards.
Default tests need no Lua interpreter or parser installation. No generator grants
native admission or declares a Quest complete because its source file was found.

Source operation categories and ordered AST nodes preserve Lua syntax. Receiver
identity, runtime scope/global assignment, scheduler activation, helper execution
and native owner semantics remain separately qualified. Source-offset order of NPC
events is not runtime execution order. Directory matches remain candidate-only.
