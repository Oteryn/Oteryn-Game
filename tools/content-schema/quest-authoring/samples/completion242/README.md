# Completion of the 242 existing SOURCE definitions

The frozen selection covers the 242 `waiting_data` definitions at parent
`0bdc2f404b1f75fae8fa05ecb48bcef65159765c`. These are definition records, including
several families that represent more than one wiki title. `covered_wiki_titles`
records the exact existing direct/family join; it does not invent new aliases.

Each existing identity receives an `oteryn_recipe` supplement with a finite chosen
Oteryn journey, concrete requirements, ordered objectives, reward intentions,
repeat policy and explicit adaptations. These chosen recipes supplement the donor
graphs. They do not overwrite donor requirements, claims, progress, interactions,
source references or fidelity holds. Full original-definition digests enforce this
boundary. The 42 definitions outside the selection and the preceding 68 authored
definitions are preserved.

All behavior, counts and delivery policies in a recipe are explicitly
`CHOSEN_OTERYN_APPROXIMATION`. A chosen recipe can be complete while the historical
donor projection still has unknowns or importer gaps. Its `waiting_native_bindings`
status refers to executable target, trigger and delivery bindings; it never enables
runtime or certifies official Tibia fidelity. Family grouping, simplifications and
unsupported official behavior must be recorded in the recipe's adaptations.

Exact wiki references remain checked against the original specifications. The six
definitions without an exact wiki-title counterpart use real pinned Git evidence
instead of fabricated wiki IDs. Family context is additional research with its own
provenance. Original wiki dialogue/source bodies remain research cache material,
not redistributed recipe text.

The historical readiness field `unresolved_items` is a broad diagnostic counter:
it includes transcription omissions, conflicts and gate/track coverage holds. It
does not count missing Item definitions. Counts across quest owners can repeat the
same interaction. Genuine Source reconstruction repairs require separate exact
source witnesses and qualification; a chosen recipe never silently clears them.

```sh

```
